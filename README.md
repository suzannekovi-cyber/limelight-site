# Limelight Actors Studio website

Plain HTML/CSS site, ready for Vercel. No build step.

## Files
- `index.html` — Home
- `meetsuzanne.html` — Meet Suzanne (keeps the old Wix address /meetsuzanne)
- `self-tape-services.html` — Self-Tape Studio (keeps /self-tape-services)
- `styles.css` — colors, fonts, layout for every page
- `script.js` — mobile menu and contact form
- `vercel.json` — clean URLs and redirects for old Wix links
- `images/` — photos and logo

## Contact form
The form is connected to Web3Forms and emails SuzanneKovi@comcast.net. The access key is in each .html file.

## Change prices or text
Open the .html file on GitHub, click the pencil icon, edit the words, and click Commit. Vercel republishes automatically in about a minute.
